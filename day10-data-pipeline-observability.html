PHA 2 XÂY DỰNG DATA PIPELINE Mỗi người 65 phút

📡 Ingestion — crossref.py

Gọi Crossref API, retry/backoff khi 429/503. Lưu hai dạng raw artifact: response.json (thô) + records.json (đã parse)

🧹 Cleaning — cleaning.py

Bóc thẻ XML/HTML, chuẩn hóa ngày, tính age_days, tạo text_for_embedding. Lưu CSV + JSON sạch.

❄️ Eval Set — testset.py

Tạo ≥ 5 câu hỏi factual từ clean data, gắn ground_truth_doc_ids. Đóng băng bộ test → lưu test_set.json.

📊 Observability — quality.py

Viết checks: completeness, uniqueness, freshness. Sinh file báo cáo chất lượng dữ liệu.

🔑 paper_id phải unique và non-null — khoá liên kết xuyên suốt 3 trạng thái

Quên chạy pip install -e . — chỉ chạy requirements.txt là chưa đủ.
02
GOOGLE_API_KEY is required
File .env chưa có key hoặc không được load. Kiểm tra tên biến và đường dẫn.
03
Điểm metrics không thay đổi sau khi gây lỗi
Corruption nhầm vào tài liệu không nằm trong test_set.json. Kiểm tra overlap với ground_truth_doc_ids.
04
Crossref API trả về 429 / 503 liên tục
Kiểm tra retry/backoff trong crossref.py. Hoặc dùng raw snapshot do Coach cung cấp sẵn.
05
NotImplementedError khi chạy pipeline
Đọc traceback để biết chính xác file + hàm nào chưa được hoàn thiện theo TODO.
